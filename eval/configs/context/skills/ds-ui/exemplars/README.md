# Примеры

Сюда кладутся короткие фрагменты из реальных экранов: **хорошо** и **плохо**, с ID правила.
Источник — принятые PR и разборы прогонов пилота. Один пример — один файл.

Формат файла `exemplars/<правило>.md`:

````md
# form/destructive-label

## Плохо
```tsx
<Button variant="danger">OK</Button>
```

## Хорошо
```tsx
<Button variant="danger">Удалить проект</Button>
```

Почему: из кнопки должно быть понятно, что произойдёт, без чтения текста модалки.
````
