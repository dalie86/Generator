# Экраны, которые генерирует агент

Каждая задача эксперимента — своя папка: `src/screens/T01/`.

Внутри агент создаёт:

- `index.tsx` — экран, `export default function Screen()`;
- `Screen.stories.tsx` — story с id `screens-t01--default`, по нему идут проверки доступности.

Прогоны идут в ветке `pilot-runs`. После замеров копия экрана сохраняется в `eval/results/screens/<задача>-<конфигурация>-<номер>/`, а папка здесь очищается перед следующим прогоном.
